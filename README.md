# HTML & CSS Project

## Project Description
This project is built using HTML5 and CSS3. The goal is to practice web development fundamentals, including page structure, styling, and Flexbox a little.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Git & GitHub

## Project Structure
```text
my-new-project/
├── index.html
├── style.css
└── README.md
```

## Features
- Simple HTML structure
- CSS styling
- Flexbox layout
- Simple and organized code

## How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. Alternatively, use the Live Server extension in VS Code.

## Learning Objectives
- Understand HTML elements and structure.
- Apply CSS properties.
- Practice Flexbox layouts.
- Improve frontend development skills.
- Learn Git and GitHub version control.
